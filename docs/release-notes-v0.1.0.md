# v0.1.0 — 首个公开版本

> May the Beacon show you what TODO.

BeaconTODO 是一款本地优先的桌面待办管理器：把一件事拆成有序节点，把关键节点标成里程碑，把正在推进的待办钉成桌面置顶小窗。

零账号、零网络请求，安装包不到 2 MB。

## 下载

| | 文件 | 大小 | 说明 |
| --- | --- | --- | --- |
| **安装版**（推荐） | `BeaconTODO_0.1.0_x64-setup.exe` | 1.96 MiB | 走安装向导，创建开始菜单/桌面快捷方式，可在「应用和功能」中卸载 |
| **便携版** | `beacon-todo.exe` | 4.84 MiB | 免安装，双击即用，不写注册表；删文件即卸载 |

**系统要求**：Windows 10 / 11（64 位），需要 WebView2 运行时（Windows 11 已内置）。

> 便携版只便携「程序」，不便携「数据」—— 数据固定存放在 `%APPDATA%\com.beacontodo.app\`。

macOS 版本由 CI 做构建验证，本版暂不提供正式产物。

## 亮点

### 节点化拆解，进度不再靠感觉

一件事拆成有序节点，每个节点可单独勾完成，进度按节点自动计算。「等保整改」不再是黑盒，而是「还剩 2/4 步、卡在复测」这样一句可核查的判断。

节点拖拽**只调整顺序，不改动日期、里程碑、完成状态等任何属性**——这条规则有独立的回归测试守着。

### 里程碑 = 节点上的一个开关

不需要单独维护「里程碑列表」。任意节点行内拨一下滑块就是 `◆` 里程碑，卡片上随即出现 `◆ 已完成/总数`。

### 桌面置顶小窗

任意待办可以钉成一扇无边框、始终置顶的小窗：

- 自由拖动并记住位置，重启后原地恢复
- 单独 pin 与合并 pin 两种模式，多个待办可在同一小窗内切换
- 同一待办不重复开窗，再次置顶会聚焦已有窗口
- 窗内可直接新建、编辑、勾节点，改动实时同步到主窗口

### 三种视图看同一份数据

- **列表**：卡片流，优先级徽章 + 进度 + 里程碑计数，点击卡片就地展开节点直接勾选
- **日历**：横条横跨起止日期，起始日带优先级短标；未开始灰、已开始稳定随机色
- **状态看板**：未开始 / 进行中 / 已逾期 / 已完成四列，跨列拖拽即改状态

### 窗口透明度只淡化背景

主窗口与置顶小窗各有一个 35%–100% 的透明度滑块，**只淡化背景色块，文字与图标始终清晰**，重启后自动恢复。

### 本地优先

数据存在本地 SQLite，不联网、不登录；启动自动备份并保留最近 5 份；支持全量 JSON 导出 / 导入。

## 这个版本修掉的问题

开发过程中被真实使用反复顶出来的问题，已全部修复：

- 编辑弹窗点 × 关不掉（关闭后被自动重开）
- 删除待办后弹出 `todo not found`（虽然记录其实已删除）
- 删除待办后，置顶小窗里仍挂着已删除的条目
- 调透明度时文字跟着一起发灰
- 点击同一个待办的置顶，会重复开出多个小窗
- 置顶小窗阴影过重（Windows 11 的 DWM 系统阴影，非 CSS 所致）
- 在小窗里新建的待办不出现在主窗口
- 列表卡片不显示进度（节点数据未被加载）

## 已知限制

- 没有到期提醒和重复任务（下一版优先做）
- 没有云同步，多设备需要手动导出/导入（本地优先是刻意选择）
- macOS 未做交互适配，仅验证可构建
- 未做代码签名，首次运行可能出现 SmartScreen 提示，点「更多信息 → 仍要运行」即可
