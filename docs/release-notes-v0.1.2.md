# v0.1.2 — 日期选择器重做、待办置顶、删除分组三选

> May the Beacon show you what TODO.

这一版把三处「用着别扭」的地方重做了：日期控件、删除分组、以及置顶语义的拆分。

## 下载

| | 文件 | 说明 |
| --- | --- | --- |
| **安装版**（推荐） | `BeaconTODO_0.1.2_x64-setup.exe` | 走安装向导，创建开始菜单/桌面快捷方式，可在「应用和功能」中卸载 |
| **便携版** | `beacon-todo.exe` | 免安装，双击即用，不写注册表；删文件即卸载 |

**系统要求**：Windows 10 / 11（64 位），需要 WebView2 运行时（Windows 11 已内置）。

## 本版新增

### 日期选择器重做

原来的日期框是原生 `<input type="date">`，点击后会把焦点落到「年」那一段并选中它——既像 bug，样式又改不动。现在换成自绘日历面板：

- 点击弹出月历，可前后翻月，今天空心描边、选中实心
- 底部「今天」一键填入，另可「清除」
- 面板浮在弹窗之上（不再被内容区裁切）
- 彻底脱离原生控件，配色跟随主题

### 待办置顶

新增独立的「置顶」开关（图钉图标）：

- 置顶的待办**在全局视图和所属分组里都排到最前**
- 再点一次取消，顺序回到原位
- 卡片头部显示图钉标记，一眼看出哪条被钉住
- 导出 / 导入会保留置顶状态

### 删除分组的三个选项

原来是 `window.confirm` 的二选一：**[确定] 迁移待办、[取消] 连待办一起删**——把最危险的操作绑在「取消」上，按 Esc 就等于删光整组。

现在改成和删除待办同一套主题化确认框，两个选项各自写明后果：

| 选项 | 实际行为 |
| --- | --- |
| 仅删分组 | 把 N 个待办迁移到「默认分组」 |
| 删除分组及所有待办 | 红色标记「不可撤销」，N 个待办及其节点永久删除 |
| 取消 | 什么都不做 |

空分组、没有其他分组可迁移时，文案会相应改写而不是留下死路。

### 设置里的「关于」页

设置面板拆成「通用 / 关于」两个标签。关于页显示：

- 版本号（读自构建产物，不硬编码）
- 运行环境：系统版本、架构、WebView2 完整版本、数据库状态与 schema 版本、数据目录
- GitHub 图标入口，点击用系统默认浏览器打开仓库

## 命名调整

「单独置顶」更名为**「悬浮窗」**，图标换成两层叠窗口。原因是本版新增了真正的「置顶」（列表排序），两者用同一个图钉会混淆——现在：

- **悬浮窗**：把待办钉成桌面小窗，随时勾选
- **置顶**：只影响列表顺序，不产生窗口

## 修复

- 导出后再导入会丢失置顶状态（导入语句漏了新字段）

## 维护

- 新增 Release workflow：推 `v*` 标签、发布 Release 或手动触发时，自动构建并上传安装包与便携版到对应 Release
- GitHub Actions 升级到 Node 24 运行时，消除弃用警告

## 升级说明

数据库会自动迁移到 **schema v3**（`todos` 表新增 `pinned` 列，默认 0）。老数据不受影响，不需要任何手动操作；升级会覆盖安装，待办与设置都会保留。

## 已知限制

- 没有到期提醒和重复任务
- 没有云同步，多设备需要手动导出/导入
- macOS 未做交互适配，产物未签名，首次打开需在「系统设置 → 隐私与安全性」中允许
- 未做代码签名，Windows 首次运行可能出现 SmartScreen 提示，点「更多信息 → 仍要运行」即可
